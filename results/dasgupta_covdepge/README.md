# Generated BRCA results

Run `experiments/dasgupta_covdepge/run_brca_fit.R` to create:

- `brca_covdepge_fit.rds`: fit, exact inputs, settings, checksums, runtime, warnings, and session information.
- `fit-summary.txt`: concise human-readable run metadata.

Generated result files are ignored by Git because they are reproducible from the versioned data and scripts. The rendered HTML report is kept beside its QMD under `experiments/dasgupta_covdepge/`.
